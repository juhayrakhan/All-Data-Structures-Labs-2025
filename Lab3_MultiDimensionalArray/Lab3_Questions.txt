Q1. Match the Tables Game
Suppose there is a game known as "MATCH THE TABLES", in which the player picks up two tables (each having 5 rows and 5 columns) and matches them. If out of 25 entries at least 20 corresponding entries match then the tables are said to be identical and the player is declared the winner. Implement this in C++ using template.

Q2. Class Records & Statistical Analysis
Write a program to keep records and perform statistical analysis for a class of students. The class may have up to 10 students. There are three quizzes during the term for computer programming. Each student is identified by a four digit roll no. The program will print the student scores and calculate and print the following statistics:
High score & Low score for each quiz along with the roll number of that student.
Average of Each Quiz and overall average of all the 3 quizzes.
Highest Average and Lowest average of all the three quizzes along with quiz no.
Highest marks & lowest marks of each student in the 3 quizzes along with the quiz no.

Q4. Euclidean Norm of a 2D Array
Write a C++ program using template that calculates the Euclidean norm (also known as the L2 norm or magnitude) of a vector represented by a 2D array. The Euclidean norm is defined as the square root of the sum of the squares of all elements in the vector.
Given array: Vector = [[3, 4], [2, 1]]
Norm = sqrt(3^2 + 4^2 + 2^2 + 1^2) = sqrt(9 + 16 + 4 + 1) = sqrt(30)

Result = [1, 4, 7, 10, 11, 12, 9, 6, 3, 2, 5, 8]

Q10. Salesperson Monthly Performance Analysis
Write a program to record and analyze sales figures for a retail team. The team has up to 10 salespersons, each identified by a 4-digit employee ID. Performance is recorded across 3 quarters in a 2D array. The program prints all sales records and computes:
Highest and Lowest sales for each quarter along with the employee ID.
Average sales of each quarter and the overall combined average.
Highest and Lowest quarter averages along with the quarter number.
Highest and lowest sales achieved by each salesperson along with the quarter number.
