A binary tree is height-balanced if, for every node, the heights of its left and right subtrees 
differ by at most 1. Write a function isBalanced(Node* root) that returns “True” if the tree is 
height-balanced and “False” otherwise. 
Example: 
 
Figure 2: At the root the subtree heights are 3 and 1, so the tree is not balanced.

False

Question 1 (Easy)
The values in a binary tree are not stored in any order, so the largest or the smallest value can be at any position in the tree. Write two recursive functions findMax(Node* root) and findMin(Node* root) that return the largest and the smallest value in the tree. Do not copy the values into an array or any other data structure.
Example:

Figure 2: The maximum (orange) and minimum (blue) values are both leaves.
Output:
Maximum: 31
Minimum: 2
Explanation: The largest value 31 and the smallest value 2 are both leaves in the left subtree, and the root (12) is neither the maximum nor the minimum, so every node has to be compared.
Question 2 (Medium)
The left view of a binary tree is the set of nodes that can be seen when the tree is viewed from the left side, i.e. the first node of every level. Write a function leftView(Node* root) that prints the left view of the tree from top to bottom.
Example:

Figure 6: The left view is the first node of every level.
Output:
1 2 4 7
Explanation: The first node of each level is 1 (level 0), 2 (level 1), 4 (level 2) and 7 (level 3). Node 4 is a right child and node 7 is in the right subtree, but they are still visible from the left because no other node comes before them on their level.
Hint: use a level order traversal with a queue, or a recursive function that also passes the current level.
Question 3 (Hard)
You are given the preorder and inorder traversals of a binary tree in two arrays. All values are unique. Write a function buildTree(int preorder[], int inorder[], int n) that constructs the original binary tree and returns its root. To verify your tree, print its level order traversal.
Example:
Input:  Preorder: 1 2 4 7 3 5 6 8
Input:  Inorder:  4 7 2 1 5 3 8 6

Figure 11: The tree constructed from the given traversals.
Output:
Level order: 1 2 3 4 5 6 7 8
Explanation: The first value of the preorder (1) is the root. In the inorder array, everything to the left of 1 (4 7 2) belongs to the left subtree and everything to the right (5 3 8 6) belongs to the right subtree. Applying the same rule recursively on each part gives the tree shown, whose level order traversal is 1 2 3 4 5 6 7 8.
Hint: keep an index into the preorder array that moves forward every time a node is created.

The lowest common ancestor (LCA) of two nodes n1 and n2 is the deepest node that has both n1 and n2 as descendants (a node is also a descendant of itself). Write a function findLCA(Node* root, int n1, int n2) that returns the LCA of n1 and n2. Assume that all values are unique and both values are present in the tree. The tree is not a binary search tree, so the values cannot be used to decide whether to go left or right.
Example:
Input:  n1 = 7, n2 = 6
Input:  n1 = 7, n2 = 8
Input:  n1 = 4, n2 = 5

Figure 9: LCA of 7 and 6 (blue) is 5 (orange).
Output:
5
3
5
Explanation: 7 and 6 are both in the subtree of 5, and 5 is the deepest such node, so the LCA is 5. 7 is in the left subtree of the root and 8 is in the right subtree, so the LCA is the root 3. 4 is a descendant of 5, so the LCA of 4 and 5 is 5 itself.
