Task 1: ArrayList Class — Core Operations
Implement the ArrayList class (int-based) with the following members:
class ArrayList {
private:
    int* arr;
    int capacity;
    int count;
public:
    ArrayList(int size);
    ~ArrayList();
    bool isFull() const;
    bool isEmpty() const;
    int  getSize() const;
    bool insert(int index, int value);
    bool remove(int index);
    int  search(int value) const;
    int  get(int index) const;
    bool replace(int index, int value);
};

Requirements:
insert(index, value): shift elements right to open a slot; fail (return false) if the list isFull() or the index is out of range (0 to count inclusive).
remove(index): shift elements left to close the gap; fail (return false) if the list isEmpty() or the index is out of range (0 to count-1).
search(value): linear search; return the index of the first match, or -1 if not found.
get(index): return the value stored at the given index; fail by printing an error message and returning -1 if the list isEmpty() or the index is out of range (0 to count-1).
replace(index, value): overwrite the element at the given index with the new value; fail (return false) and leave the list unchanged if the list isEmpty() or the index is out of range (0 to count-1).
This class is the foundation for Task 2 and Task 3 — add the new functions listed below directly to it.

Task 2: ArrayList — reverse() and removeDuplicates()
Add the following two member functions to the ArrayList class from Task 1:
void reverse();
int  removeDuplicates();

reverse()
Reverse the order of the currently stored elements in place (do not use a second array).
Example: [10, 20, 30, 40] -> [40, 30, 20, 10].
removeDuplicates()
Remove duplicate values from the list, keeping only the first occurrence of each value and preserving the original relative order.
Shift the remaining elements left to close gaps and update count accordingly.
Return the number of duplicate elements that were removed.
Do not use an auxiliary array/vector larger than a small counting helper if needed; work within the existing array.
Example: [10, 20, 10, 30, 20, 10] -> list becomes [10, 20, 30], function returns 3.

Task 3: ArrayList — findMinMax() and rotateLeft()
Add the following two member functions to the same ArrayList class:
void findMinMax(int& minVal, int& maxVal) const;
bool rotateLeft(int k);

findMinMax(minVal, maxVal)
Traverse the list once, updating minVal and maxVal by reference to the smallest and largest values stored.
Edge case: if the list isEmpty(), print an error message and leave minVal and maxVal unchanged.
rotateLeft(k)
Rotate the elements of the list to the left by k positions.
If k is larger than count, use k % count to avoid redundant full rotations.
Return false (and leave the list unchanged) if the list isEmpty(); otherwise perform the rotation and return true.
Example: [1, 2, 3, 4, 5] rotated left by 2 -> [3, 4, 5, 1, 2].

Task 4: Singly Linked List 
class Node {
public:
    int data;
    Node* next;
    Node(int val);
};

class LinkedList {
private:
    Node* head;
public:
    LinkedList();
    ~LinkedList();
    bool isEmpty() const;
    void insertAtStart(int value);
    void insertAtEnd(int value);
    int  search(int value) const;
    int  countNodes() const;
};

Requirements:
insertAtStart(value): create a new node and make it the new head (same idea as in the manual).
insertAtEnd(value): traverse to the last node and attach the new node there; if the list isEmpty(), the new node simply becomes head.
search(value): return the zero-based index of the first node containing value, or -1 if not found.
countNodes(): return the total number of nodes currently in the list (0 for an empty list).
~LinkedList(): free every node so there are no memory leaks.
Example: insertAtStart(10); insertAtStart(20); insertAtEnd(30); -> list is 20 -> 10 -> 30 -> NULL, countNodes() returns 3, search(10) returns 1.

Question 1: Generic Linked List Class using Templates in C++ (Must for all sections)
Class Requirements
You need to design a singly linked list class using templates.
It should have:
Node<T> class: contains
T data
Node<T>* next
LinkedList<T> class: contains
Node<T>* head (pointer to first node)
int counter (tracks number of nodes)
Note: head and counter must be declared public (not private) — the provided test file accesses list.counter directly.
Operations to Implement:
Insertion Functions
void insertAtHead(T item)
Insert a new node at the start of the list.
void insertAtTail(T item)
Insert a new node at the end of the list.
bool insertAfter(T itemToInsert, T existingItem)
Find existingItem and insert itemToInsert after it. Return true if existingItem was found and the insertion happened, false otherwise.
bool insertBefore(T itemToInsert, T existingItem)
Find existingItem and insert itemToInsert before it. Return true if existingItem was found and the insertion happened, false otherwise.
Utility Functions
bool isEmpty() const
Returns true if the list has no elements.
int search(T item) const
Returns the 0-based index of the first node containing item, or -1 if the item is not found.
void print() const
Prints all elements of the list.

Question 3 
Write a member function: 
 
void rotateRight(int k); 
Given a singly linked list, rotate the list to the right by k places. 
• 
Requirements: 
o If k is larger than the length of the list N, take k mod N to avoid redundant 
complete rotations. 
o Connect the original tail node to the original head node to form a temporary ring, 
traverse to the new break point, set the new head, and sever the ring with nullptr. 
• 
Example: 
o Input: 1 -> 2 -> 3 -> 4 -> 5 -> NULL, k = 2 
o Output: 4 -> 5 -> 1 -> 2 -> 3 -> NULL
