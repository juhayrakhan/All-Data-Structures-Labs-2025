Question 1 — Function Template: isInRange
Write a template function isInRange that determines whether a given value lies within a specified inclusive
range, defined by a lower bound and an upper bound.
Prototype: bool isInRange(T value, T low, T high)
Example:
isInRange(5, 1, 10)
-> true
(5 is between 1 and 10)
isInRange(15, 1, 10)
-> false
(15 is outside the range)
isInRange(1, 1, 10)
-> true
(bounds are inclusive)
Question 2 — Function Template: maxOfThree
Write a template function maxOfThree that accepts three values of the same generic type and returns the
largest among them. The function should operate correctly for integer, floating-point, and character data
types.
Prototype: T maxOfThree(T a, T b, T c)
Example:S
maxOfThree(3, 7, 5)
-> 7
maxOfThree(2.5, 9.9, 4.4) -> 9.9
maxOfThree('a', 'z', 'm') -> 'z'
Question 3 — Class Template: Rectangle<T>
Design a template class Rectangle that stores the width and height of a rectangle using a generic numeric
type. The class should provide the following member functions:
• area() computes and returns the area
• perimeter() computes and returns the perimeter
• scale(T factor) proportionally scales both dimensions by the given factor
• isSquare() returns true if the rectangle's width and height are equal
Example:

Rectangle<int> r(4, 5);
r.area();
// 20
r.perimeter();
// 18
r.scale(2);
// width = 8, height = 10
r.isSquare();
// false
Question 4 — Class Template: BankAccount<T>
Design a template class BankAccount in which the account balance is represented using a generic type,
allowing instantiation with either integer or floating-point balances. The class should provide the following
member functions:
• deposit(T amount) increases the balance by the specified amount
• bool withdraw(T amount) decreases the balance by the specified amount, returning false and leaving
the balance unchanged if the withdrawal would result in a negative balance
• getBalance() returns the current balance
Example:
BankAccount<double> acc(200.0);
acc.deposit(50.0);
// balance = 250.0
acc.withdraw(75.0);
// true,
balance = 175.0
acc.withdraw(1000.0);
// false, balance unchanged (175.0)

Q1. Define a template class Container for storing different type of values e.g. int, double, 
float etc. This container would keep same type of values/elements at a time. The 
Container class should consist of the following member variables: 
• T * values; A pointer to set of values it contains. This member points to the 
dynamically allocated array (which you will be allocating in constructor). 
• capacity; An integer that shows total capacity of the container. 
counter; An integer counter variable which increments upon every insertion operation and 
decrements upon removal of any element; representing total number of elements currently 
present in the container. 
The container should consist of following functions: 
• constructor with capacity as parameter 
• isFull which will return true if counter reaches capacity otherwise false 
• insert which will receive a value of some type (int/double/float) and insert into the 
container if it’s not already full 
Prototype: void insert(T) 
• search which will return true if the container contains value passed as parameter 
Prototype: bool search(T) 

• remove which will remove a value, if exists, from the container and shifts all 
subsequent values one index back. 
Prototype: void remove(T) 
print which will print all values contained in the container.
