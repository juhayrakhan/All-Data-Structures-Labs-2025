Define a template Container in C++ program to sort a given unsorted array of integers in 
wave form.

    T *arr;

};

Q4. Template Array Container
Define a class template ArrayContainer that stores an array dynamically and provides functions to calculate the sum, average, and largest element.
Prototype:
template <typename T>
class ArrayContainer
{
private:
    T* arr;
    int size;
public:
    ArrayContainer(T input[], int size);
    T calculateSum();
    double calculateAverage();
    T findLargest();
};
The class should dynamically allocate memory in the constructor and release it using a destructor.
